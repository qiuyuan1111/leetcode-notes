# 1784. 检查二进制字符串字段（Check if Binary String Has at Most One Segment of Ones）

题目链接： https://leetcode.cn/problems/check-if-binary-string-has-at-most-one-segment-of-ones/

## 标签
- 字符串
- 一次遍历
- 计数

## 思路
题目要求：字符串中 `'1'` 的连续段（segment）最多只能出现 1 段。

你的实现使用“相邻字符是否发生变化”来判断：
- 从下标 1 开始遍历
- 如果 `s[i] != s[i-1]`，说明发生了一次“段切换”，计数 `check++`
- 一旦切换次数 `check > 1` 就返回 false

因为如果 `'1'` 段超过 1 段，字符串形态必然包含类似 `...1...0...1...`，这会产生至少两次切换（`1->0` 和 `0->1`），从而 `check > 1`。

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 易错点
- 字符串长度为 1 时一定满足条件
- 不要把“切换次数”误认为“1 的段数”，这里用的是等价判定：出现第二次切换意味着 `'1'` 不可能只是一段
- 注意遍历从 1 开始，比较 `s[i]` 和 `s[i-1]`
